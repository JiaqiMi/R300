V25 仅修复运行状态与刷新恢复，不修改任何启动顺序或底层算法：

1. 页面刷新后，状态不再只依赖 dashboard_server 内存中的 Popen。
   会只读检查实际 ROS 节点：相机/YOLO、1X、雷达感知、高程、雷达 Web 适配器。
2. 已存在相机/视觉节点时，点击“启动相机/视觉”不会重复启动第二套节点。
   避免同名 ROS 节点互相踢掉，以及双 YOLO 瞬时重复占用 GPU。
3. 点云/高程 JSON 订阅与 Web 包装进程状态解耦。
   刷新后只要 /r300_lidar_web_adapter 仍在运行即可恢复显示；
   启动相机返回的状态数据不会再错误退订高程话题。
4. 端口保持不变：网页 8090，rosbridge 9090，视觉 MJPEG 8080。
   不新增第二个 rosbridge 端口。
